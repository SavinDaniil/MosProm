# Проверка этапа A

Проверяемые заявления: рабочая проходная от первого лица; сцены 3.1–3.5; только два посетителя; бесплатное сопоставление; отдельный платный запрос; явное окончательное решение; независимые интересы; локальное сохранение; читаемый мобильный стол.

Внутренней прокрутки текста и горизонтальной прокрутки вкладок нет. Проверяются scrollHeight/clientHeight, границы текста и полей относительно листа, отсутствие пересечения текста с кнопками перелистывания. На телефоне вкладки равномерно заполняют два ряда. На мониторе справочные тексты показываются целиком, если помещаются; вместимость пересчитывается при повороте и изменении размера.

Дополнительные исследовательские ситуации: несколько быстрых запросов подряд; смена ориентации с выбранным полем; возврат к исправленной заявке; отказ инженеру; пропуск технолога без уточнения; отказ при нулевом остатке; перезапуск из середины и из конца.

Тестовые состояния с нулём запросов подготавливаются через хранилище, поскольку в двух случаях этапа A при одном запросе на посетителя естественный минимум — один оставшийся запрос. Это проверка будущего совместимого состояния, а не третья сцена.
