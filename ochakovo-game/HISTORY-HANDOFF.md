# История «Очаково»: локальная доработка v4

Статус: готова и подключена к локальной игре. По просьбе пользователя не публиковалась: другие игровые этапы параллельно дорабатываются в другом чате.

## Что изменено

- Семь глав и 21 короткая сцена вместо четырёх обзорных экранов.
- Сюжет: открытие перед Олимпиадой → трудности и реконструкция → экспедиции за рецептами → региональные заводы → продолжение традиции кваса → новые напитки → команда и первая задача игрока.
- Иллюстрированные переходы, постепенное обновление оборудования, схема развития площадок, две культуры брожения, интерактивная линейка напитков.
- Реплики и эмоции существующего маскота через GameMotion.coach.
- Навигация назад, по главам и по сценам; дополнительные детали и первоисточники раскрываются по желанию. Таймера и викторины нет.

## Файлы и подключение

Новая история: `dist/history-narrative.js`, `dist/history-narrative.css`, `dist/assets/history-expedition-v4.png`.

Зависимости из существующей игры: `style.css`, GSAP, `motion.js`, `companion.js`/`companion.css`, изображения `factory-map.png`, `history-factory.png`, `history-recipes.png`. Они не включены в отдельный архив истории и уже находятся в проекте.

В текущем `dist/index.html` уже подключены `history-narrative.css?v=4.2` и `history-narrative.js?v=4.2` вместо старых `history.css`/`history.js`. При объединении параллельных изменений сохраните новые подключения. Не заменяйте весь index.html или app.js старой копией.

В app.js изменены только подписи истории: «Семь глав об одной компании» и «Мини-история „Очаково“». API сохранён: `GameStory.mount(container, onComplete)` возвращает cleanup; завершение возвращает `id: intro`, `score: 100`, `role`, `learned`, `nextId` выбранной профессии. Открытие профессии остаётся обязанностью существующего приложения.

Полный текст — HISTORY.md. Происхождение новой иллюстрации — ASSET-PROMPTS-HISTORY.md. Общие README, REQUIREMENTS и TESTING не обновлялись в этом финальном проходе, чтобы не затронуть параллельную работу.
