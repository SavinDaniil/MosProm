# Объединение с mosv3.0 · 24.10.2026

Итоговый проект: `MosProm-merged`. Запуск из этой папки: `sh start.sh`
(Windows: `start.bat`). Игра находится в `ochakovo-game/dist/`.

## Как объединены версии

- Сохранены текущие этапы 3 и 5: `floor-model.js`, `floor-scenes.js`, обе
  таблицы стилей floor, иллюстрации, журнал, объяснения, осмотр бутылок,
  сверка коробок с накладной, изоляция повреждений, резервная замена и отгрузка.
- Сохранены история, рисованная лаборатория и общая оболочка из текущего
  проекта. Сравнение с `mosv3.0/ochakovo-game/dist` подтвердило, что эти
  реализации уже совпадали с импортируемой версией с учётом окончания строк
  и оформления общего помощника.
- Из `mosv3.0` перенесены актуальные `engineering-story.js` и
  `engineering-story.css`: выбор оснастки, регулировка зазора, цепочка
  автоматики, терминал, пробные циклы, осмотр трёх банок, подсказки у объектов,
  журнал и передача результата. Обновлён URL скрипта для сброса старого кеша.
- Сохранены Очажок и его изображения из текущего проекта. Собственные
  иллюстрации наставника лаборатории и инженерии также доступны.
- Сохранены прежние лабораторные и инженерные реализации, страницы их
  предпросмотра, исходный розлив и модель складского заказа из шести коробок.
  Новые эпизоды по-прежнему регистрируются последними для основного маршрута.
- Ключи сохранений, паспорт открытий, свободный маршрут, практика, анкета,
  управление анимацией и запускатели не заменялись.

Ни один файл из `dist` обеих исходных папок не отсутствует в результате.
Изменения относительно `mosv3.0` вне инженерии относятся к подключению новых
этапов, оформлению помощника и уже существовавшим доработкам лаборатории.
Все буквальные локальные ссылки на скрипты, стили, шрифты и изображения
проверены: отсутствующих ресурсов нет.

Исходные папки `MosProm-codex-mosprom-upload` и `mosv3.0` не изменялись.
Резервные копии заменённых файлов, исходного индекса незавершённого слияния
и контрольные суммы ресурсов находятся рядом с проектом:
`../merge-backups/2026-10-24-mosv3/`.

## Необходимые проверки

- 29 проверок логики: текущие розлив и склад, исходные розлив и склад,
  рисованная лаборатория и сохранённая лабораторная механика v10.
- Полное браузерное прохождение обновлённой инженерии: неправильные решения,
  контекстные подсказки, восстановление после перезагрузки, журнал,
  завершение и сохранение открытия.
- Полное браузерное прохождение розлива и склада при ширине 1440 и 390 px:
  ошибки, журнал, объяснения, повреждение и замена, сверка заказа,
  восстановление прогресса и возврат на карту.
- Открытие всех пяти участков, карты, паспорта и практики при 1440 и 390 px;
  отдельный вход `laboratory.html`. Проверены JavaScript-ошибки, загрузка
  ресурсов и отсутствие горизонтального переполнения.

В среде проверки передача ресурсов через loopback зависала и с Python, и
с временным сервером Node. Для браузерных прогонов Playwright передавал
неизменённые файлы `dist` напрямую через перехват запросов. Проверено
поведение игры; полноценная HTTP-доставка в этой среде не подтверждена.

Повторный запуск проверок логики из корня проекта:

```sh
node --test --test-isolation=none ochakovo-game/tests/*.test.cjs
```

Для браузерных проверок нужен установленный Playwright и сервер игры:

```sh
GAME_URL=http://127.0.0.1:4174 node ochakovo-game/tests/merged-route.browser.cjs
GAME_URL=http://127.0.0.1:4174 node ochakovo-game/tests/floor-interface.browser.cjs
```

При необходимости `PLAYWRIGHT_MODULE` задаёт путь к модулю Playwright,
а `BROWSER_PATH` — путь к исполняемому файлу Chromium.
