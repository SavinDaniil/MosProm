# Соответствие игровой части кейса · v3

| Требование | Реализация |
|---|---|
| Рабочий инструмент | Браузерная игра, пять участков, паспорт и карьерное продолжение |
| Лёгкая игра | Свободный маршрут, без таймера и штрафов; несколько связанных действий |
| История компании | Четыре главы: открытие 18.12.1978 и Олимпиада-80, рецепты, бренды, команда; точки исследования и управляемое учебное брожение |
| Ключевые бренды | Очаковский, Семейный секрет, CoolCola, Fancy, Street, Toness |
| Рассказ о профессиях | Роль, объяснения этапов, реакции наставника, смена, инструменты и навыки; условия практики в карьерном разделе |
| Лаборатория | Приёмка, регистрация, подготовка, контроль приборов, pH и °Brix, журнал, оценка требований, немедленное удержание и уведомление, назначенный повтор отдельной записью, заключение и передача специалисту; шесть последовательных этапов |
| Розлив | Параметры выпуска, три станции, увеличение, шесть решений и три вида дефектов |
| Инженерия | Разговор с оператором, схема, шесть кадров, сопоставление источников и гипотез, работа специалиста, два прохода и пустой промежуток, запись и согласованное возобновление; самостоятельного ремонта нет |
| Склад и логистика | F-78: получение задания, адреса хранения, два формата CoolCola, лишние товары, самостоятельный отбор количества, сканирование и осмотр, сверка без автозаполнения, возврат и повторная проверка, сообщение о повреждении, резервная замена и передача в зону отгрузки; итог из журнала действий |
| Технологический цех | Брожение в истории и отдельное направление практики |
| Контроль понимания | Решения по показаниям, параметрам, дефектам, сигналам и размещению; объяснение ошибки и повтор |
| Маскот | Постоянная колонка на ПК, компактный вариант на телефоне, три позы, жесты, подсказки и сворачивание |
| Фирменный дизайн | #D50032, исходный логотип, белые и кремовые поверхности, красная одежда, панели оборудования |
| Анимации | GSAP: проба/пипетка/прибор, три станции, сортировка, коробки, ворота/палета/машина |
| Доступность | Клавиатура и нажатия для всех обязательных действий; дополнительное перетаскивание; фокус, статусы, мобильная адаптация, пауза и снижение движения |
| Карьерные возможности | Пять направлений, наставничество и условия из материалов |
| Данные кандидата | ФИО, контакт, дата рождения, направление, готовность выйти, учебное заведение; дополнительные поля |
| Совершеннолетие | Полная дата рождения, анкета работы/практики с 18 лет |
| Контакт с компанией | Подготовка .txt и официальный канал отклика, автоматическая отправка не имитируется |
| Граница объёма | Нет отдельной бренд-платформы, мерча и сопутствующей кампании |
