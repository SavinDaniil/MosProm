# Первая смена — Очаково

Готовый сайт с пятью игровыми этапами. Сборка и установка Node.js не нужны.

## Запуск

**Linux / macOS:** из этой папки выполните `sh start.sh`.
Нужен Python 3.7 или новее.

**Windows:** откройте `start.bat`. Если Python отсутствует, запускатель
предложит автоматическую установку; для неё нужен интернет.

Адрес сайта: http://127.0.0.1:4174/. Остановка сервера: Ctrl+C.
Другой порт: `sh start.sh --port 4175`.
Без открытия браузера: `sh start.sh --no-browser`.
